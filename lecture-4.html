JS Basics: Variables, Data Types, and Flow Control

In this lesson, you will learn the fundamental logic that gives a website its brain. Get ready to write your first lines of JavaScript!

Goal: Master the "grammar" of JavaScript—the logic that gives your website its brain.

1. Introduction: The Engine of the Web

If HTML is the metal chassis of a car and CSS is the paint and seats, then JavaScript is the engine and the dashboard.
Without JavaScript, a website is just a static piece of paper—it looks nice, but it can't do anything. JavaScript (JS) allows the page to "think," respond to clicks, calculate data, and change its content without needing to reload the entire page.

The Three Core Jobs of JavaScript:

JavaScript performs three main tasks to make the web feel "alive":

  1. Listen (Events): JavaScript waits for the user to do something.
    • Examples: Clicking a button, typing into a search box, hovering over an image, or scrolling to the bottom of the page.
  2. Think (Logic): JavaScript processes information and makes decisions based on user interactions.
    • Examples: Validating form inputs, calculating totals, or showing/hiding elements based on user actions.
  3. Act (DOM Manipulation): JavaScript changes the content or appearance of the webpage based on user interactions.
    • Examples: Updating text content, changing CSS styles, or showing/hiding elements based on user actions.

2. Variables: The Storage Boxes

To make a website interactive, we need to save information to use later. We do this using variables. Think of a variable as a labeled storage box in a warehouse. You put a piece of data inside, slap a label on the box, and use that label whenever you need to find that data again.

In modern JavaScript, we use two main keywords to create these boxes:

  • const (Constant): Use this for data that never changes.
    • Examples: The value of pi (3.14), the URL of your website, or the name of your company. These are things that should never change once set.
  • let (Variable): Use this for data that can change.
    • Examples: A user's name, the number of items in a shopping cart, or the current temperature.

3. Data Types: What’s in the Box?

JavaScript needs to know what kind of information you are putting in the "box" so it knows how to handle it. Here are the three most important types:

  1. Strings (The "Sticky Notes")A String is simply text. JavaScript doesn't try to understand it or do math with it; it just reads it exactly as written. You always wrap strings in quotation marks.
    • Examples: "Hello, World!", "John Doe", or "2024-06-01". Even if it looks like a number, if it's in quotes, it's a string and treated as text.
  2. Numbers (The "Calculator Input")Numbers are exactly what they sound like. You use them when you need the computer to calculate, count, or measure something. You never use quotation marks for numbers.
    • Examples: 42, 3.14, or -10
  3. Boolean (The "Light Switch")A Boolean is the simplest data type. It only has two possible settings: true or false. These are the foundation of all website logic.
    • Examples:Imagine a website's "Dark Mode." Behind the scenes, there is a variable acting as a switch: let isDarkModeOn = false;. When the user clicks the button, JavaScript flips it to true.

4. Flow Control: Making Decisions

Websites need to be "smart." They need to make decisions based on user actions. This is called Flow Control.

  • if/else statements: These allow the program to choose different paths based on certain conditions.
  • Loops (for) What if you have to greet 100 people? You wouldn't write the code 100 times. You use a loop to tell the computer to repeat an action until a condition is met.
